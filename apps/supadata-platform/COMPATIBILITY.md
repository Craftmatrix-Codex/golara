## Versioned SDK evidence

`compat/sdk-inventory.json` is generated from the pinned official SDK declarations and lists 223 public callable surfaces across 20 areas, including Auth passkeys/custom providers and alpha vector/analytics Storage APIs. It is an inventory of signatures, not a behavioral coverage percentage. Its unverified entries remain unverified until individual contract evidence is linked.

The initial executable contracts cover invalid password handling, admin listing/signup/create/delete, password/session/refresh/logout, database CRUD/upsert/single/maybeSingle/HEAD count/range, combined filters, quoted IN values and secondary ordering, RPC, singleton mutation rollback, anonymous database privilege rejection, Storage upload/list/download/remove, public Realtime channel lifecycle, and a deployed Deno function. Browser checks cover desktop/mobile sign-in and menu sign-out, failed logout with retry, SDK-created user visibility and default deletion readback in Studio, session-based access, public project metadata, runtime failures, and public-origin destinations. Malformed Auth deletion requests must fail before changing the account. See `compat/README.md` for target configuration and fixture setup.
